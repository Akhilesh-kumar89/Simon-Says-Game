🎮 Simon Says Game

A simple and fun memory game built using HTML, CSS, and JavaScript where players must repeat the sequence of colors shown by the game. The sequence becomes longer as the level increases, making the game more challenging.

🚀 Features
Interactive gameplay
Random color sequence generation
Increasing difficulty with levels
Score/level tracking
Responsive and beginner-friendly UI
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
🎯 How to Play
Press any key to start the game.
Watch the color sequence carefully.
Repeat the same sequence by clicking the buttons.
Each level adds a new color to the sequence.
Game ends if you click the wrong color.
